Falling Target

A rifle fires at a target that lets go the instant the shot leaves the barrel. Where should you aim?

Setup

Instructions
  1. Press Fire to see what happens. The target is released at the moment the bullet leaves the rifle.
  2. Press Pick target up, then change the target's height or distance with the sliders.
  3. Use Angle to tilt the rifle up or down, or press Aim at target to point the laser straight at it.
  4. Change the bullet speed. Does a faster bullet change where you should aim?
  5. Turn gravity off and fire again. What is different, and what stays the same?
Theory

It feels as if you should aim a little below the target, because the target is falling. Gravity pulls on the bullet too, so the net effect is that no correction is needed. The rifle points straight at the target's starting position and the bullet still hits.

The simplest case has the target level with the rifle. The bullet's horizontal velocity is constant if air resistance is ignored. Its vertical motion is a free fall, ½gt². The target falls ½gt² in the same time. At every instant the two are at the same height, so the bullet still hits.

When the target is above or below the rifle the argument takes one more step. Write the bullet's position as its straight aim line plus a drop of ½gt². Write the target's position as its starting point plus the same drop. A bullet that meets the target at the start point on the aim line meets it wherever the drop has carried both.

It fails only if the target reaches the ground before the bullet reaches it. Raise the bullet speed until it works.
