Hinge question, 90 seconds. Count to three and every board goes up at once, so nobody copies. Scan before you speak. Each wrong answer is one specific error: A counted only the 4p, C added the 3d, D counted every electron (that is Z). If more than a third are not on B, reteach with the gallium shell slide before the exit ticket. If nearly all are on B, move on. Cold call one student per letter to defend it.
