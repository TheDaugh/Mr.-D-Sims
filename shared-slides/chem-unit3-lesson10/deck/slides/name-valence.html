Predict on the sheet first: how many valence electrons does gallium (31 electrons) have? Some will say 13 (they counted 3d, 4s and 4p). Run the animation: each shell is a ring, filling from the inside out, and the configuration for that shell appears beside it. The point is the 3d: it filled after 4s, but its n is 3, so it sits in the third ring with the core. Ask: which number tells you the shell? The big one. Valence is only the outermost ring: 4s² and 4p¹, so 3.
