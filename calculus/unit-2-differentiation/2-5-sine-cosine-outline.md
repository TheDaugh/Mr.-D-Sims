# 2.5 Derivatives of Sine and Cosine: outline

**Big question.** If you trace the slope of y = sin x at every point, what curve do you get?

**Goal.** Every student differentiates sine and cosine terms, evaluates exactly with the unit circle, and explains the cosine rule's minus sign, at their own level.

## Flow (about 60 min, two parts)
**Part A**
1. **Warm-up (4 min).** Six skills; silently places each student on one of four paths.
2. **Predict (4 min).** Guess sine's slope graph, then test it: slope 0 at the peak, about 1 at the origin.
3. **Explore (15–20 min).** Slope Tracer sim. Estimate slopes from a run-1 triangle; dots draw cos x, then −sin x. Zoomed secants at π/3 connect the limit definition to the rule.
4. **Huddle (3 min).** Class code unlocks the rest. Students state the rules in words.

**Part B**
5. **Build (8 min).** Differentiate, read the unit circle, check the sign.
6. **Practice (12 min).** Eight adaptive problems.
7. **Check (7 min).** Four items, no hints; pass is 3 of 4 including the idea item. A miss routes to recovery and a second form.
8. **Wrap-up (5 min).** Summary, hand-in code, printable notes.

## Paths (hidden)
| Path | Support | Stretch |
|---|---|---|
| Build | f′(x), unit circle, f′(a) | 3cos x − 2x |
| Apply | f′(x), f′(a) | limits as derivatives, tangents |
| Stretch | f′(a) and tangent | sign of f′, f′ = 0 |
| Extend | result only | 4-cycle, f″ + f = 0, proof |
