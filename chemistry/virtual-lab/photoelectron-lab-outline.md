# Photoelectron Spectroscopy virtual lab (slot 11) · outline

**URL:** `chemistry/virtual-lab/index.html?lab=pes` · **Target T9:** match a PES spectrum to an element (peak position = subshell energy, peak height = electron count) and draw the spectrum for a configuration.

| Min | Step | Student does |
|---|---|---|
| 0-4 | Hook, three cards | Unlabeled spectrum, "what element?"; photoelectron, binding energy, peak |
| 4-12 | Part A | Lithium: sweep the light, watch where electrons first appear. Then Ne, Na, S, one free choice. Checkpoint 1: read a spectrum |
| 12-22 | Part B | Draw O, Mg, Si; compare each with the real run. Checkpoint 2: draw |
| 22-33 | Part C | Mystery cells A-D (rising difficulty), flawed claim. Checkpoint 3: match |
| 33-42 | Parts D, E | Model A against neon; draw P last |
| 42-50 | Paper | The worksheet is the graded record |

**Gate:** each checkpoint is 3 right in a row. A miss shows a hint from the student's own answer, then a new variant. Three misses in a row, or I need Mr. D, lock the screen. Mr. D types the PIN; that type then needs 2 fresh variants.

**Not here (Ian's overrides):** pre-predictions, huddles, warm-up, bands, finger votes, typed post-questions or CER, print slip, end stamp.

**Data:** Z 1-20. Outermost energies are NIST first ionization energies. 42 inner or valence energies are calculated free-atom values (NIST SRD 141), marked in the key.
