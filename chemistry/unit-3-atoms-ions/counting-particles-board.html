Vocabulary

Proton
Positive particle in the nucleus. The proton count names the element.
Neutron
Neutral particle in the nucleus. It adds mass.
Electron
Negative particle outside the nucleus.
Atomic number (Z)
The number of protons.
Mass number (A)
Protons plus neutrons.
Ion
A particle with unequal protons and electrons, so it has a charge.
Cation / anion
Positive ion (lost electrons) / negative ion (gained electrons).
Isotopes
Atoms of the same element with different numbers of neutrons.

Core ideas

  1. The number of protons decides which element an atom is.
  2. Neutrons change the mass, not the element.
  3. Only electrons are gained or lost when a particle becomes an ion.
  4. Charge = protons − electrons. More electrons than protons is negative.
  5. Carbon-14 means mass number 14. It has 8 neutrons, not 14.
