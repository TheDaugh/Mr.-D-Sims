# Free-Body Diagrams and Net Force: Slot 4 Outline

**Format:** online guided lesson. Open `fbd-net-force.html`. Add `#key` for the teacher key on every screen. Codes and the report reader are on `teacher.html`. The projector page is `fbd-net-force-projector.html`.

## Big idea
A free-body diagram shows every force on one object, one arrow each. The net force is what is left after the arrows on a line cancel. Net force sets the change in motion, not the motion.

## Misconceptions targeted
"Motion needs a force in its direction" (the extra arrow). "Normal always equals weight" (arrow size).

## Sequence
1. **Warm-up.** Vectors and Proportions Check, six items: add forces on a line, direction of a net force, ratio table. It sets the start level. Direction misses get the 1D arrow table first; six right flags the student for the slot 20 incline work.
2. **Predict.** Three one-try predictions.
3. **Explore.** The force catalog: click each force, see source object, receiving object, contact or field.
4. **Huddle.** A three-diagram check-in gives each student a three-letter code (C, M, X, S). The teacher pastes codes into the projector page to see the class split, then gives the huddle code.
5. **Build.** About twelve items, six simple source and catalog questions before each diagram, then diagrams for rest, steady motion and speeding up, then net force. Two-object items appear only for fast finishers.
6. **Practice and Check.** Practice runs to the end mark. Check is one diagram and one net force.
7. **Notes.** Print or download, then the stamp.

## Projector page
Six situations for the whiteboard hold-up, tally buttons, class split, a common-errors list that writes tomorrow's warm-up, and jump buttons to vocabulary and core ideas.

## Differentiation
Four hidden bands. Each response logs rung, misses and seconds to the report code.
