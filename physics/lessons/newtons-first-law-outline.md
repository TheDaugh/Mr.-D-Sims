# Newton's First Law: Day 1 Outline

**Format:** online, about 45 minutes. Open `newtons-first-law.html`. Add `#key` for the teacher key on every screen. Codes, answer key and a report reader are on `teacher.html`.

## Big idea
Motion needs no force. Changing motion does. Zero net force means constant velocity.

## Misconception targeted
"A moving object needs a continuing push."

## Sequence
1. **Warm-up (3 min).** Five items set a silent starting level, 1 to 4.
2. **Predict (5 min).** Three predictions, each with confidence and a written reason.
3. **Investigate (15 min).**
   - A: six surfaces, stopping distance and time.
   - B: does mass change the distance? (No.)
   - C: find the push that keeps it cruising (F equals friction; zero on ideal ice).
   - D: balance several forces so the path stays straight.
4. **Huddle 1 (4 min).** Teacher code. Predictions against evidence. Student writes the rule.
5. **Name it (8 min).** Explanation in three registers, the law as a fill-in, free-body diagrams, vocabulary in the student's own words.
6. **Try it (8 min).** Six questions, four levels each, routed up or down by performance.
7. **Check (5 min).** Huddle 2 code. Identical questions for all, plus reflection.
8. **Notes.** Print as PDF or download LaTeX. Stamp and report code.

## Differentiation
Levels run from middle-school wording to AP and first-year college (components, equilibrium, inertial frames). Numbers are seeded per student. Everyone ends on the same check.

## Teacher tools
Daily codes, per-student answers with `#key`, a Preview band control, and a table reader for report codes.
