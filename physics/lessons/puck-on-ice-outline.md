# Puck on Ice: Newton’s First Law (Outline)

**Day 1, online, about 40 minutes. Day 2, hands-on fan carts.**
**Teacher key:** open `puck-on-ice.html#key`

## Big idea
Without a net external force, velocity does not change. Friction usually stops moving objects, so the rule shows when friction shrinks.

## Misconception targeted
"A moving object needs a push to keep moving." Option A on the predict screen.

## Sequence

| Step | Min | Students | Teacher |
|---|---|---|---|
| 1 Predict | 0–4 | Lock one answer before any run | Watch the class poll |
| 2 Play with a job | 4–16 | Run five surfaces and frictionless; log distances | Walk the room |
| 3 Huddle | 16–20 | Enter class code, write the rule | Give code at minute 16 |
| 4 Name it | 20–24 | Copy the formal statement | Check wording |
| 5 Try it | 24–34 | Three questions; difficulty adjusts | Watch the device log |
| 6 Check | 34–40 | One common diagnostic, then reflection | Read the distribution |

Day 2 (not in this file): fan cart on a low-friction track, predicting the velocity-time graph with the fan on and off.

## Differentiation (hidden)
Each question has three rungs: A core, B transfer, C extension. A clean first try moves a student up. One miss holds. Two or more misses move down, with the reasoning shown. Every student answers three questions and takes the same Check.

## Key features
- Predict locks before the sim runs.
- Huddle code changes daily.
- Teacher key logs rung, misses, and seconds for this device only.
