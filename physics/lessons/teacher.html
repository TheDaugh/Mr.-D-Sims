Teacher page

Today’s codes, the answer key, a stamp checker, and a table reader for student report codes. Nothing here is sent anywhere; it runs in this browser.

Today’s codes

Check a stamp

A student shows a stamp like NFL-1234 or N2L-1234 at the end. Type their first name and period to see what it should be today.

Read report codes

Paste one student report code per line (they copy it from the Notes step, or you collect them through Classroom). The table shows starting band, how the band moved, misses, predictions, check results and time per step.

Answer key

Sample numbers shown. Each student’s numbers differ. For a particular student’s answers, open the lesson with #key on the address or use the red Preview band control; the key shows the numbers for that device.
